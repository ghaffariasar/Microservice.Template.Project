# CQRS و معماری تمیز

- فرمان‌ها و کوئری‌ها با MediatR در لایه Application قرار دارند.
- AutoMapper برای نگاشت بین Domain و DTO استفاده می‌شود.
- Result Pattern برای خروجی یکنواخت Handlerها به‌کار می‌رود.
- وابستگی‌ها در لایه Infrastructure ثبت می‌گردند و API تنها ورودی/خروجی HTTP را مدیریت می‌کند.
